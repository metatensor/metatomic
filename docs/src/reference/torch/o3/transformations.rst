O(3) transformations
====================

The :py:mod:`metatomic_torch.o3.O3Transformations` class provides functions to
rotate and invert :py:class:`~metatomic_torch.System` and
:py:class:`~metatensor.torch.TensorMap` objects, for example to generate
randomly rotated copies of a structure for data augmentation.
